# История изменений

## 2.1.0 (versionCode 4) — 2026-11-19
- Раздел «Сеть и прокси» во всех четырёх дизайнах, один общий движок подключения.
- Режим Reyohoho Proxy (по умолчанию выключен): модальное предупреждение о передаче OAuth-токена,
  версионированное согласие, отзыв, токен только в заголовке `X-Auth-Token`, только мастер-плейлист,
  откат на прямое подключение.
- Свой HTTP/SOCKS5-прокси для gql/usher, пароль шифруется Android Keystore.
- Кнопка «Повторить через Reyohoho» в плеере (если согласие дано), строка маршрута в панели плеера.
- Диагностика: режим, маршрут, сервер, страна usher, макс. качество, откат и причина; маскирование
  `X-Auth-Token`, `Proxy-Authorization`, `user:pass@`, `auth=` в логах.
- Тесты: ConnectionTest (26), скриншоты «Сеть и прокси» и окна согласия для каждого дизайна.
