# Отчёт о тестировании — Twitch TV 1.0

Дата: 2026-11-18, ~22:00–22:30 MSK. Среда сборки: Debian 13 aarch64, JDK 17, AGP 8.7.3, Gradle 8.11.1.

> **Важно.** Приложение НЕ запускалось ни на физическом телевизоре TCL, ни в эмуляторе Android TV
> (в среде сборки нет KVM и ADB-устройства). Всё ниже — сборка, статическая проверка APK,
> JVM/Robolectric-тесты и проверки против живого API Twitch с сервера сборки.

## 2. Юнит-тесты HLS / обхода рекламы (JVM) — ПРОЙДЕНО

`HlsTest`, 4/4:
- разбор master-плейлиста (разрешение, FPS, кодек, битрейт);
- обнаружение и вырезание рекламных сегментов, коррекция MEDIA-SEQUENCE;
- чистый плейлист не изменяется;
- fMP4: `EXT-X-MAP` рекламы не попадает к live-сегментам, правильный MAP восстанавливается.

## 3. Проверка против живого Twitch (с сервера сборки, без VPN) — ПРОЙДЕНО

`LiveTwitchTest` (`-Dlive=true`):
- Популярное: 30 стримов, первый — rubius (~331 тыс. зрителей).
- Категория «Grand Theft Auto VI» найдена (id 1867279146, ~2,79 млн зрителей), получен список стримов.
- Поиск «rubiu» → rubius, rubikyt_, rubini (все в эфире); статус канала — работает.
- Токены воспроизведения `site` / `popout` / `embed` → 1080p60, 720p60, (720p), 480p, 360p, 160p; `autoplay` → 360p/160p.
- Реальный сегмент rubius 1080p60: HTTP 200, ~2,0 МБ; init-сегмент fMP4 HTTP 200;
  ffprobe: H.264 Main 1920×1080 60 fps, кадр декодирован без ошибок.
- Реклама: в одном случае (kaicenat, токен `embed`) плейлист целиком состоял из рекламы
  (4 сегмента вырезано, live-сегментов 0) — подтверждает, что нужен переход на другой резервный
  токен, а не просто вырезание. Остальные 15 проверок — без рекламы.

## 4. UI-смоук (Robolectric, Compose, ТВ-конфигурация 960×540dp land television) — ПРОЙДЕНО

`UiSmokeTest` (живая сеть):
- Запуск MainActivity, загрузка «Популярного» с реальными карточками.
- Навигация только событиями D-pad: вкладка GTA VI → Поиск → История → Настройки и обратно.
- OK на карточке открывает плеер (ExoPlayer создаётся, экран сменяется), Back возвращает на главный экран.

Найдено и исправлено этим тестом:
- **Баг:** при старте автоматический фокус попадал на первую вкладку и молча переключал экран на
  пустое «Избранное». Исправлено: фокус ставится на выбранную вкладку, смена вкладки по фокусу —
  только после нажатия клавиши; стартовая вкладка — Избранное, если оно не пустое, иначе Популярное.

Замечание: в Robolectric одно нажатие «вправо» сразу после загрузки вкладки GTA VI не переключило
вкладку (следующие — штатно). Вероятно, артефакт тестового окружения; проверить на ТВ.

Ограничения теста: Robolectric не рендерит видео и не использует аппаратные декодеры — проверено,
что плеер создаётся и экран работает, но не то, что видео реально показывается.

## 5. НЕ ПРОВЕРЕНО (требует телевизора)

1. Установка и запуск на TCL Google TV; модель ТВ неизвестна.
2. Реальное воспроизведение видео в ExoPlayer на устройстве, плавность 1080p60, отсутствие пропуска кадров.
3. Работа через Happ Proxy (выборочная маршрутизация по пакету `su.expensive.twitchtv`),
   переподключение при перезапуске Happ / смене сети, определение «VPN: да».
4. Аппаратный HEVC/AV1 на TCL и потоки 1440p60 — в протестированных каналах Twitch выдал только H.264
   до 1080p60; ветка 1440p/HEVC и откат на H.264 при ошибке декодера проверены только кодом.
5. Обход рекламы в реальном времени: переключение на резервный поток во время рекламной паузы
   и возврат на основной (проверено на синтетических плейлистах и одном живом случае без плеера).
6. Автоснижение/повышение качества при реальных ребуферах.
7. Кнопки пульта TCL: CH+/CH−, Play/Pause, долгое OK (коды клавиш у разных пультов отличаются).
8. Чат в реальном времени и эмоуты 7TV/BTTV/FFZ на ТВ; нагрузка на CPU/память.
9. Экспорт лога в Download на конкретной прошивке.
10. Release-сборка после R8 запускалась только как статически проверенный APK — UI-тест выполнялся
    на debug-варианте.

## Что сделать после установки

Открыть стрим → OK → «Диагностика»: проверить «VPN: да», разрешение/кодек, имя декодера, пропуски
кадров. Настройки → «HEVC / 1440p» покажет, есть ли аппаратный HEVC. При проблеме — «Экспорт лога»
и прислать файл (токены в нём вырезаны).
