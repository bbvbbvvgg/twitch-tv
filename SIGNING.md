# Ключ подписи TwitchTV

Все обновления `su.expensive.twitchtv` нужно подписывать **одним и тем же** ключом. Если ключ
потерян, новую версию не получится поставить поверх старой: придётся удалить приложение, и
избранное, история и настройки пропадут.

## Отпечаток (не секрет, по нему проверяют подлинность)

- Alias: `twitchtv`, хранилище PKCS12, RSA 3072
- SHA-256 сертификата: `F6:52:57:1F:89:60:B8:B0:B8:74:F5:B6:91:AB:DD:E5:D7:54:13:85:AF:EE:E0:8F:2D:83:1D:3C:32:9A:66:EB`

```
apksigner verify --print-certs TwitchTV-*.apk   # SHA-256 должен совпасть с этим
```

## Что НЕ лежит в репозитории

`keystore/`, `*.jks`, `*.p12`, `*.gpg`, файлы паролей закрыты в `.gitignore`. Пароль в
`build.gradle.kts` не записан: он берётся из переменной окружения `TV_STORE_PASS` или из
свойства Gradle (`~/.gradle/gradle.properties`, вне репозитория).

## Передача владельцу

Ключ передаётся файлом `twitchtv-signing-key.tar.gpg`. Это архив, зашифрованный OpenPGP
(AES-256, S2K SHA-512 с максимальным числом итераций). Внутри `twitchtv.jks` и
`SIGNING.txt` с паролем хранилища. Парольная фраза к архиву передаётся **отдельно** и в
репозиторий не попадает.

Расшифровка (GnuPG; на Windows — Gpg4win, на macOS — GPG Suite):

```
gpg -d twitchtv-signing-key.tar.gpg | tar -xf -
# появится папка twitchtv-signing/ с twitchtv.jks и SIGNING.txt
```

Хранение: парольную фразу и пароль хранилища положите в менеджер паролей. Держите две
офлайн-копии `.tar.gpg`, например на флешке и в личном облаке; зашифрованный файл без фразы
бесполезен. Расшифрованный `.jks` после сборки удаляйте или держите только на своей машине.

## Сборка release

```
mkdir -p keystore && cp twitchtv-signing/twitchtv.jks keystore/
export TV_STORE_PASS='…'      # из SIGNING.txt; не сохраняйте в файлах проекта
./gradlew assembleRelease
```

Без ключа или пароля `assembleRelease` завершится ошибкой, а не тихо подпишет APK
debug-ключом. Debug-подпись release-сборки возможна только явно:
`-PallowDebugSigning=true`. Такой APK не обновит установленное приложение.

CI (если появится): ключ кладётся в секрет как base64 (`base64 -w0 twitchtv.jks`), пароль — во
второй секрет. На runner'е ключ восстанавливается в `keystore/` перед сборкой.
